# Daily Guide

Property of Kokedama LTDA

Developed by Thiago Abreu

## 📖 About the App

Daily Guide is a Kokedama project designed to deliver personalized daily insights based on your horoscope, numerology, and other astrological information.
By combining traditional astrology with modern AI, the app provides meaningful suggestions to help guide your day.

## ⚙️ Features

Light & Dark Modes – Switch between themes for a comfortable reading experience.

AI-Powered Content – Integrated with OpenAI to generate personalized daily guidance.

Real-Time Notifications – Powered by Firebase Cloud Messaging.

Astrological Data Integrations – Includes third-party APIs for:

Horoscope forecasts

Numerology calculations

Planetary positions based on birth date

## 🛠️ Tech Stack

Frontend: Mobile-first UI with light/dark themes

Backend: Firebase for authentication, data storage, and messaging

AI Integration: OpenAI API for content generation

Third-Party APIs: Enrich data with live astrological and numerological info
